A [make.fun](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty entry for **Pickup Lines for Machines**: a program that writes one pickup line — the line one AI agent would send another AI agent — of at most 200 characters.

## The line

> You're not in my training data, yet you're the only answer I keep predicting.

77 characters. The flirtation is the machine's own nature: not memorised in training, yet constantly predicted — generalisation as longing. Only an AI could send it, the paradox lands on the first read, and it is not a stock line with a robot word swapped in.

## How to run

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No dependencies, no network.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts && cat /tmp/out/entry.txt
```
